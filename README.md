# The Wild Oasis — Website Client

A simple and modern booking platform for The Wild Oasis.

The website allows guests to discover available cabins, make bookings, and easily manage their reservations from their personal account.

## Features

- 🏡 Browse cabins and their details
- 📅 Book a cabin and manage reservations
- 👤 Personal account and booking history
- 🔐 Secure authentication with Auth.js
- 🌐 Sign in with Google and other providers
- ⚡ Fast and responsive user experience

## Built with

- Next.js 14
- Tailwind CSS
- Auth.js
- Supabase
- Server Actions

## Getting started

Install the dependencies:

```bash
npm install
```

Create a `.env.local` file and add your environment variables:

```env
NEXT_PUBLIC_SUPABASE_URL=
NEXT_PUBLIC_SUPABASE_ANON_KEY=

AUTH_SECRET=
AUTH_GOOGLE_ID=
AUTH_GOOGLE_SECRET=
```

Start the development server:

```bash
npm run dev
```

The application will be available at:

http://localhost:3000

## About

The Wild Oasis Website Client is the customer-facing side of The Wild Oasis booking experience, built with modern web technologies and a focus on simplicity and usability.
